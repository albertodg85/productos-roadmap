## 🏗️ Estructura

### Issues
- Todas las features están organizadas como **Issues**
- Etiquetadas por: producto, trimestre, mes, tipo (feature/bug/improvement)
- Vinculadas a milestones por trimestre

### Project Board
- **Vista de Kanban**: Backlog → In Progress → In Review → Done
- **Vista de Tabla**: Filtros por producto, trimestre, mes, assignee
- **Vista de Roadmap**: Timeline visual de hitos

### Discussions
- Estrategia general de productos
- Feedback de usuarios
- Decisiones arquitectónicas

---

## 🎯 Cómo Usar Este Roadmap

### Para Desarrolladores
1. Ve a **[Projects](./projects)** → Selecciona producto
2. Filtra por trimestre/mes actual
3. Mueve issues de "Backlog" a "In Progress" cuando comiences
4. Actualiza el status en tiempo real

### Para Product Managers
1. Usa la **vista de Timeline** para ver el roadmap completo
2. Revisa el progreso en la **vista de Tabla**
3. Participa en **Discussions** para feedback

### Para Stakeholders
1. Consulta el **README de cada producto** para visión general
2. Revisa la **vista pública del Project Board**
3. Síguete en **Discussions** para actualizaciones
