# 🚀 goSail - Roadmap Detallado

## 📋 Descripción

**goSail** es una plataforma de navegación y gestión náutica que proporciona herramientas inteligentes para navegantes, veleros y profesionales marítimos.

### Repositorio
- [goSail](https://github.com/albertodg85/goSail)

### Stack Tecnológico
- Frontend: TypeScript/React
- Backend: Node.js/Express
- Base de Datos: PostgreSQL
- Mapas: Mapbox/Leaflet
- Real-time: WebSocket

## 💰 Monetización

### Modelo Freemium
- **Free Tier**: Features básicas, máximo 10 rutas
