# 🌊 seaPilot - Roadmap Detallado

## 📋 Descripción

**seaPilot** es un sistema inteligente de navegación marítima que proporciona recomendaciones de rutas optimizadas, monitoreo de condiciones marítimas y seguridad para navegantes profesionales y aficionados.

### Repositorio
- [seaPilot](https://github.com/albertodg85/seaPilot)

### Stack Tecnológico
- Frontend: JavaScript/React
- Backend: Node.js/Express
- Base de Datos: PostgreSQL
- Geolocalización: Mapbox, PostGIS
- Weather API: OpenWeatherMap, NOAA
- Mobile: React Native
